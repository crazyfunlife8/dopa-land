## 1. 產品定位
- **服務**：AI 看你的圖，**星盤 或 人類圖 二選一**。
- **形式**：AI 文字分析（網頁呈現＋可下載圖卡／PDF）。
- **調性**：延續采潔「被說中＋笑出來」，厭世幽默、實用乾貨。
- **在階梯裡的位置**：**入口款 = AI 99** → 升級到 **真人老師語音對症**（老師定價、平台抽成）。呼應網站 FAQ「純計算機器算得出來，深的個人化才需要人味」。

## 2. 定價
- **AI 分析：99 元 flat（單一價，不分級）。**
- **為什麼單一價**：AI 邊際成本近零、即時無限量 → 用低門檻鉤子走量，把「深／完整／對症」讓給真人老師，階梯才乾淨。
- 舊的 **98 單題／168 完整 兩級 → 取消**（168 的「深講」角色由真人老師接手）。
- 笑聲加購：不上架（綁語音，暫緩）。

---

## 3. 交付與架構（本次核心・已定 B）
- **即時交付**：付款 → 網站「巴巴驗證機」**當場算＋出解讀**，不排隊、不限量。
- **兩步架構**：
  1. **計算核心（JS 算盤・大魔王）**：出生年月日時地 → 人類圖（類型／權威／定義／profile／閘門）。確定性天文＋人類圖數學，純前端可跑（如 Astronomy Engine），不用後端。
  2. **生文字＝B（計算庫數據＋寫好的公式模板）**：每個屬性配一段預寫文案，依算出的盤組裝成解讀。→ 準、即時、零 API 成本、采潔語氣完全可控、**零亂講命理風險**。
- **A（LLM API）之後當加值層**：要「對症回答自由提問」時再接；須有後端藏金鑰，並「把算好的事實餵給 AI、禁止它自編類型／權威」才不亂講。
- **交付物**：網頁結果 ＋ 可下載 **圖卡／PDF**（好收藏、好轉發＝免費宣傳）。
