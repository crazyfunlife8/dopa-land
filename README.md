人類圖分析網站的完整前端。**所有畫面都做完了，但全部是空殼**——資料存在瀏覽器的 localStorage，重開別台裝置就沒了。你要做的是把這些空殼接到真的後端。

## 先跑起來看

純靜態，沒有 build step、沒有 npm、沒有框架（原生 JS，ES5 語法）。

```bash
cd frontend && python -m http.server 8000
```

打開 http://localhost:8000 。**必須用 http 開，不能用 `file://`**（外部 js/css 會被 CORS 擋掉）。

建議先自己走一遍這幾條路徑，比讀文件快：

1. 首頁 →「先進場驗證身份」→ 填生日 → 看結果（**這段是真的在算，不是假資料**）
2. 深度解析 →「解鎖完整分析」→ 結帳（試試不勾同意框會怎樣）→ 付款結果
3. 深度解析 →「找真人老師」→ 點老師卡 → 預約 → 結帳 → 我的訂單 → 聽錄音 → 評價
4. 登入（假的，按下去就登入）→ 取暱稱 → 寫自介 → 進大廳 → 摩天輪／飛車 →「想認識」→ 信箱

## 現在是假的、要換成真的

| 前端現況 | 要換成 |

| 按登入就直接建一個假帳號 | Google／LINE OAuth（**只做社群登入，不做 email/密碼**——不存密碼就不扛外洩責任） |

## 不能做反的事（政策已對外承諾，做反就是違約）

這幾條寫在已上線的隱私權政策與使用者條款裡，不是內部偏好：

1. **私訊不做事前審閱，平台不主動閱讀。** 不要建後台的訊息瀏覽介面、不要做關鍵字掃描佇列。只有在使用者檢舉並主動提交該段對話、或司法機關要求時才取用。
2. **公開內容才審**（樹洞紙條／自我介紹／暱稱）——這些要 AI 初篩 → 命中攔下或送人工 → 先審後顯。
3. **交易紀錄不隨帳號刪除。** 帳號刪除後 30 天內清除分析、私訊與大廳身份，但交易紀錄依法保存 5 年。
4. **結帳的必勾同意框不能拿掉、也不能預設打勾。** 「不適用七日鑑賞期」的法律前提就是購買前已告知且消費者同意；同意時間戳要留存（前端已寫進訂單的 `consent` / `consentAt`）。
5. **大廳一律不顯示性別。** 這是產品定位不是裝飾——自介、暱稱、卡片都不能有性別欄位。
6. 個資法處理期限：查閱 15 日、更正刪除 30 日（各得延長同天數）。

完整條文在 `docs/多巴樂園_政策文案_v1.md`。

## 關於 `原始單檔/`

目前對外是把整站壓成**一個 HTML 檔**發佈（圖片 base64、CSS/JS 內嵌），因為部署在只吃單檔的環境。`_template.html` + `inject.py` 是產生它的原始碼與腳本。

**你不需要沿用這套。** 這包的 `frontend/` 就是同一份程式碼的正常展開版，兩者行為一致（已逐項比對驗證）。放在這裡只是讓你對照目前線上實際跑的東西。
